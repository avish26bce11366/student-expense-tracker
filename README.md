# Campus Pocket Money Tracker

This is a simple console-based tool written in Python for the CSE 1021 course project submission.

## Features
- Save student name and monthly budget goal.
- Track expense entries categorised into Food, Transport, and Books.
- Auto-saves everything dynamically inside a local JSON format.
- Computes budget breach warnings if you cross 75% or 100% threshold marks.

## Setup and Execution Guide
1. Make sure Python 3 is installed on your computer.
2. Put all files inside a single terminal directory.
3. Open your command line / terminal or Spyder console and launch:
   ```bash
   python main.py
   ```
